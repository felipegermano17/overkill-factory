# Legacy documentation

This directory preserves old public documentation and generated historical references.

It is not the canonical public documentation. Canonical docs now live under `docs/en/` and `docs/pt-BR/`.

Use legacy docs as historical evidence only:

- to recover a useful explanation;
- to compare old promises with executable contracts;
- to understand why a public surface was removed;
- to preserve compatibility for old references.

Do not copy legacy material back into public docs without translating it into the new Documentation OS structure. Do not reintroduce old public directories such as `docs/architecture/`, `docs/operations/`, or `docs/operator/` as canonical surfaces.
