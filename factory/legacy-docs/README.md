# Legacy / technical documentation

This folder contains older technical and internal factory documentation retained for compatibility, historical reference, tests, validators and migration work.

It is not the new public product documentation.

The new public documentation lives in the repository root `docs/` folder and must be written from scratch for external readers.

Rules for this folder:

- Do not treat these files as the public explanation of Overkill Factory.
- Do not copy old text into public docs unless it is still true, useful and rewritten for a new reader.
- Keep files here only when they support compatibility, technical reference, tests, validators or migration history.
- If a file no longer has technical value, delete it in a dedicated cleanup with tests.
