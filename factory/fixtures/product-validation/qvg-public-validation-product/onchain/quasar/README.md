This is the Quasar source target for the QVG product-shaped validation fixture.

the Auditor corpus/checklist contract before the production Auditor lane can be
marked achieved for this fixture id.

Boundaries:

- no deploy;
- no devnet or mainnet write;
- no signing authority;
- no funds movement;
- no claim that this validates any private product.
