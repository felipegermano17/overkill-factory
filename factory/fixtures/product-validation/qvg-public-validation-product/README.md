# QVG Product-Shaped Validation Fixture

This directory is an advanced validation fixture used to test production-scoped
Overkill Factory lanes without using private product material.

It is not a product source tree, not an onboarding example and not a signal that
Quasar is required for every factory user. It is a public-safe, reproducible
target for proving whether strict Product Face, Quasar/Auditor, review and
completion gates still work against one product-shaped fixture.

Production-lane evidence may be reusable only for this fixture id:

`qvg-public-validation-product`
