# Overkill Factory Documentation

This is not a loose technical archive. It is the public map of the product: what the factory does, why it exists, how a request moves, what the operator sees, which evidence counts, and where the public repository stops.

Overkill Factory exists for a simple problem: agents can look busy before delivery is proven. The factory places controlled production around them.

## What this documentation does not do

It does not prove private delivery. It does not prove a live Hermes runtime ran a real card. It does not prove human approval in production. It explains the public contract and points to the evidence that would be required.

Docs, the visual map, and a local smoke can prove public repository coherence. Real delivery requires live Hermes state, current worker results, specific evidence, consumed review, Receipt Five, and a human gate when risk requires one.
