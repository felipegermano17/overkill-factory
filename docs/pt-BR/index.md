# Overkill Factory

A Overkill Factory é uma fábrica de trabalho para projetos operados com Hermes.

Ela organiza o ciclo entre pedido, fonte, entendimento, verdade do produto, rota, método, trabalho pequeno, execução, evidência, revisão, decisão e fechamento.
